# AquiVa

AquiVa es un simulador web de una aplicación móvil de pedidos construido con HTML, CSS y JavaScript puro.

## Objetivo educativo

El proyecto permite analizar UX/UI, detectar funciones faltantes, proponer mejoras de producto y practicar desarrollo frontend.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estructura

```text
AquiVa/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
├── README.md
└── vercel.json
```

## Ejecutar localmente

Abre `index.html` directamente en el navegador o utiliza Live Server.

## Deploy en Vercel

El proyecto está preparado como sitio estático para desplegarse en Vercel.

## Nota pedagógica

La aplicación es funcional pero deliberadamente incompleta para permitir que los estudiantes propongan e implementen mejoras como localStorage, autenticación, historial, favoritos persistentes, seguimiento de pedidos y nuevas funciones.
